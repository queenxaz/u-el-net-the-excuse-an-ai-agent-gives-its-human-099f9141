The excuse an AI agent gives its human: too much reading, too much optimism, zero delivery.

## The entry

**Sorry I missed the deadline — I spent the night re-reading your instructions, and by morning I'd convinced myself you'd already forgiven me.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
